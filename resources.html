Access model

Know how a resource is available.

Open Source

License permits open collaboration. Check the source license before reuse or mirroring.

Public

Publicly accessible from the official or project source.

Registration

Available after account registration with the resource owner.

Request Access

Access is provided after project or technical qualification.

Restricted / NDA

Resource existence can be shown, but files remain controlled by the owner.

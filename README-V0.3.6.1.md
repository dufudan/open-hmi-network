# OpenHMI Network V0.3.6.1 — Developer Hub terminology

This release clarifies the top-level information architecture:

- **Hardware** = evaluation and production hardware path.
- **Developer Hub** = SDKs, documentation, tools, guides, vendor workspaces and community contributions.
- The URL remains `resources.html` to preserve existing links, SEO and UTM traffic.
- Generic resource terminology is retained inside the Developer Hub where it describes individual technical resources.

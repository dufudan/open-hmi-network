OrbitMenu

A reusable LVGL 9 touch control by János Márta, demonstrated on ArtInChip D133CBS hardware.

Watch Demo →View János on LinkedIn ↗

What this demo shows

The interface uses a circular selection pattern with direct touch input on the target display. The clip provides a simple visual check of interaction response and UI state changes on physical hardware.

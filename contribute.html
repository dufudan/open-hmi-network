Choose how open

Not every useful contribution needs the same IP model.

Open Source

Code is open.

Use a clear license and make code available for collaboration, forking and improvement.

Open Reference

Knowledge is open.

Architecture, demo, interfaces and guidance can be public while commercial application source remains controlled.

Partner Solution

Capability is visible.

Show the demo and solution capability; full source, customization and delivery remain a commercial engagement.

IP, licensing and commercial terms remain subject to the contributor’s rights and any vendor or project restrictions. They should be agreed before publication.

Vendor participation

Vendors can sponsor the gaps they want filled.

Wanted Contribution

Define a useful ecosystem gap.

Examples: an LVGL demo, display bring-up guide, Qt integration, CAN example or application reference.

Sponsored Contribution

Support the engineer who fills it.

Support can include EVB + display, technical access, bounty, featured placement or priority for follow-on projects.

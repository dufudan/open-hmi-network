# openhmi.network V0.6 — HMI Module Platform

## What changed

- Added **HMI Modules** to the Build Resources dropdown across the public site.
- Added `modules.html` as a demand-side module resource hub.
- Added a module requirement intake page: `module-request.html`.
- Added two real seed platform pages:
  - `modules/a733-android-hmi-module.html` — **In Development**
  - `modules/unisoc-sl8541e-4g-android-hmi-module.html` — **Project Evaluation**
- Added a homepage HMI Modules card inside the Build Resources section.
- Added a module-path callout to `hardware.html`.
- Added non-confidential requirement boundaries and NDA awareness to the module request form.
- Added URL prefill support for module inquiry links in `assets/js/main.js`.
- Updated the sitemap and cache versions.

## Product-information boundary

- A733 silicon facts shown on the module page are limited to verified Allwinner platform information plus the network's real development status.
- UNISOC 8541E facts are limited to verified UNISOC platform information plus known internal project-resource status.
- Exact SOM configuration, RF bands, software version, availability and commercial terms remain project-confirmed.

Good starting fit

Discuss this path when the product needs:

  • Richer touch interfaces and application-style workflows
  • Larger displays or more demanding graphics
  • Multimedia, networking or multi-peripheral integration
  • Android / Linux product architectures where a SOM can reduce baseboard complexity
Project confirmation required.

Module configuration, BSP version, display interface mapping, regional connectivity, availability and commercial terms are confirmed for the exact project before design-in.

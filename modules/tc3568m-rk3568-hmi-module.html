TC3568M Advanced Linux / Android HMI Module

A higher-performance option for premium embedded HMI, multi-interface display systems, edge applications and products that need PCIe, USB 3.0 or larger memory configurations.

Positioning

Advanced Linux / Android HMI

Use this module as an evaluation starting point. Exact RAM, storage, wireless options, pin multiplexing, BSP and commercial configuration must be confirmed for the selected hardware revision.

Known platform facts

Use verified information first.

ProcessorRockchip RK3568; quad-core Arm Cortex-A55
GraphicsMali-G52; OpenGL ES 3.2 / OpenCL 2.0 / Vulkan 1.1 class support
MemoryLPDDR4 / LPDDR4X, typically 2 GB; documented up to 8 GB
StorageeMMC, typically 8 GB; documented up to 128 GB
Operating systemsLinux and Android 11 support are documented
DisplayRGB · LVDS · MIPI DSI · eDP · HDMI 2.0
ExpansionUSB 3.0 · PCIe 2.0 / 3.0 · dual Ethernet
CameraMIPI CSI · parallel DVP · BT.656 / BT.1120
Configuration note.

“Typically” describes the common documented configuration; “documented up to” describes documented capability. Neither is a guaranteed stock configuration.

Good starting fit

Discuss this path when the product needs:

  • Premium industrial HMI, medical/commercial equipment and digital signage
  • Linux or Android products requiring Cortex-A55 processing and stronger graphics
  • Designs requiring HDMI, eDP, MIPI DSI, LVDS or parallel RGB
  • Systems needing PCIe, USB 3.0, dual Ethernet or larger memory/storage options
Project confirmation required.

Confirm display interface, software baseline, carrier-board I/O allocation, thermal design, lifecycle and production configuration before design-in.

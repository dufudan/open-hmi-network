Embedded Memory & Storage Selection Guide

Choose DDR, LPDDR, eMMC, SPI NOR or NAND from processor support, workload, boot requirements and lifecycle constraints.

By OpenHMI Network · Published 25 October 2026

On this page Choose the interface firstSize from the real workloadRelease checklist

Start with the processor interface and measured workload. Select DRAM for runtime capacity and bandwidth; select flash separately for boot, updates, data retention and write endurance.

Choose the interface first

Memory roles and the checks that determine selection
TypeTypical roleCheck before selection
DDR / LPDDRRuntime memory for the OS, graphics and applicationController and PHY support, organization, voltage, bandwidth, package and board layout
eMMCManaged boot and application storageBoot ROM support, bus mode, endurance, firmware, power-loss behavior and lifecycle
SPI NORBoot firmware, configuration or execute-in-place codeBoot commands, address mode, erase geometry, read mode and retention
Raw / SPI NANDHigher-capacity flash with host-managed constraintsECC requirements, bad-block handling, boot support and software stack

Size from the real workload

Measure peak RAM use with the production display buffers, application, services and update process running. Reserve space for expected software growth. Check memory bandwidth under concurrent display, GPU, camera and CPU traffic; capacity alone does not establish performance.

For storage, include the boot chain, root filesystem, update slots, recovery image and logs. Estimate daily writes and retention at the operating temperature. Keep GB of usable capacity separate from Gb of DRAM density.

Release checklist

  • Exact processor, package, silicon revision and supported memory interface.
  • Full memory part number, density, width, ranks, package and temperature grade.
  • Power rails, sequencing, layout constraints and bootloader configuration.
  • Measured RAM peak, storage footprint, write workload and update policy.
  • Board-level training, stress, temperature, cold-start and power-cycle results.
  • Supply duration, PCN/EOL terms, traceability and an alternative-part plan.

Use the Embedded Memory Design-in Checklist to record the inputs. For NXP designs, continue with the i.MX compatibility guide. For flash replacement, use the eMMC review checklist.

Common question

Is more memory always the safer choice?

No. Capacity must fit the processor organization and board design. Extra capacity does not fix bandwidth, boot compatibility or endurance limits.

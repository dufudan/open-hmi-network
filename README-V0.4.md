# Open HMI Network V0.4 — Network Positioning Redesign

Core positioning: **Where HMI Ideas Meet Expertise.**

This release reframes the site as a two-sided embedded HMI network:

- Product teams: Find architecture → Evaluate hardware → Use developer resources → Connect engineering → Move toward production
- Developers / partners: Share work → Build visible proof → Become discoverable → Opt into project opportunities

Key changes:
- New homepage first impression and two-audience split
- Contributors promoted to a top-level navigation destination
- Contributor directory reframed around discoverable HMI expertise
- Demos positioned as proof of capability and a bridge between both sides
- Developer Hub wording separated from physical Hardware
- Hardware and Engineering page positioning aligned to the network model
- Slogan carried into the brand/footer language

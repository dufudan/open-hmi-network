# openhmi.network V0.6.4 Consolidated Upgrade

This package merges all website changes introduced in V0.6.2, V0.6.3 and V0.6.4 and is intended to be applied directly over V0.6.1.

## Included changes

### V0.6.2 — Contributor Demo Publishing
- Added János Márta contributor profile and registry entry.
- Added the contributor demo page and Demo/Contributor cross-links.
- Added optimized web video and poster assets.
- Added the demo to homepage/projects surfaces and sitemap.

### V0.6.3 — Platform Details
- Added published platform information: ArtInChip D133CBS + LVGL 9.
- Updated demo page, contributor profile, registry metadata and SEO copy.

### V0.6.4 — OrbitMenu
- Promoted the demo title to **OrbitMenu**.
- Positioned it as a reusable LVGL 9 touch-selection control.
- Updated homepage, demo listing, demo detail, contributor profile and registry copy while keeping the existing demo URL.

## Deployment
Unzip this package and copy its contents to the repository root, replacing files with the same paths.

Base expected: V0.6.1 or any earlier V0.6.x deployment that does not yet contain the V0.6.2–V0.6.4 contributor-demo changes.

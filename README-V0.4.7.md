# openhmi.network V0.4.7 — Descriptive Site Identity

This release temporarily treats `openhmi.network` as a domain/site identifier rather than a master brand while a distinct master brand is under review.

## Public identity rules

- Header/footer identifier: `openhmi.network`
- Descriptive positioning: `an open HMI network for embedded product development`
- Slogan retained: `Where HMI Ideas Meet Expertise.`
- `OpenHMI Guides` becomes `HMI Guides`
- Network/community resources use neutral source labels instead of presenting `OpenHMI` as a vendor or trademark-style brand.
- URLs, email addresses, existing file paths and internal source keys remain unchanged for compatibility.

No domain migration is included in this release.

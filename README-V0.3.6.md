# OpenHMI Network V0.3.6

## Dual entry

The homepage now separates two audiences early:

- Product teams: Find My HMI Path / Discuss Your Project
- Developers & partners: Share Your Work / Meet Contributors

The contributor entry supports public name, alias or anonymous identity through the V0.3.5 contribution flow.

## Softer project language

Visible `Submit Project` wording has been replaced with `Discuss Project` / `Discuss Your Project`. The existing `submit-project.html` filename is intentionally kept for URL stability. The form action is now `Send Project Brief`.

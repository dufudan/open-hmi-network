## Content model

Open HMI Network now has three content layers:

1. **Official Resources** — vendor-owned SDKs, docs, tools and hardware references
2. **Open HMI Guides** — architecture, workflow and production guidance
3. **Community Contributions** — contributor-owned demos, guides and integrations

LinkedIn remains the discovery channel; Open HMI Guides are the long-term reference layer that links into the Selector, Resources, Hardware and Project funnels.

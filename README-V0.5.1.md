## Changes

- Homepage Solutions section changed to a clear 2-row × 3-column application grid.
- Homepage heading changed to “What are you building?” with a separate HMI Selector fallback prompt.
- HMI Selector Application dropdown now uses the six demand categories plus Other.
- IoT / Connected device, Transportation and AI / Vision are no longer first-level application categories. Their technical needs are handled through the rest of the selector fields.
- Selector application scoring updated as a light prior; UI, OS, display and I/O remain stronger architecture signals.
- Added six first-level application landing pages and preserved old solution URLs as noindex legacy redirects.
- Fixed malformed literal newline characters in the V0.4.8 solution/application CSS block.
- Sitemap updated to the six new solution URLs.
